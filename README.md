# TrendyWear

A full-stack e-commerce platform built for a sneaker & streetwear brand.

## Project Structure
```
TrendyWear/
├── client/     # Next.js frontend
└── server/     # Node.js + Express backend
```

## Features
- Product listing with filters (price, size, brand, stock status)
- Product detail pages with image gallery and size selector
- Cart and order management
- Responsive design (mobile-first)
- "New Drop" and "Sold Out" badges for streetwear-style releases

## Tech Stack
**Frontend:** Next.js 14 (App Router), TypeScript, Tailwind CSS, Framer Motion
**Backend:** Node.js, Express, TypeScript

## Getting Started

### Frontend
```bash
cd client
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
npm run dev
```
